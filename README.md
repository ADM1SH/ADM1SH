# About Me

Hey, I'm Adam — a final-semester IT Diploma student at MMU Cyberjaya. I like taking systems apart to see how they work, whether that's code, hardware, or old cars. Recent work includes a CHIP-8 emulator hand-written in AArch64 assembly and a Snake game running straight out of an x86 boot sector.

Currently building a home setup for data science + gaming, and starting a hardware review channel to document it.

Stack: C, C++, Python, Rust, x86 / ARM / AArch64 Assembly, SQL, JavaScript, TypeScript

Interests: Cybersecurity . AI . Embedded Systems . Game Dev

Achievements: MTE Gold Medalist 2021, CS50 Graduate, Most Resilient Award

## Projects

[LLM-Inference-Quantization-Benchmarker](https://github.com/ADM1SH/LLM-Inference-Quantization-Benchmarker) — Benchmarks LLM inference and quantization performance

[hand-gesture-gamepad](https://github.com/ADM1SH/hand-gesture-gamepad) — Real-time hand gesture gamepad using MediaPipe tracking and a classifier

[console-emulator](https://github.com/ADM1SH/console-emulator) — CHIP-8 console emulator with a hand-written AArch64 assembly CPU core

[bootloader-snake](https://github.com/ADM1SH/bootloader-snake) — Bare-metal Snake game running from an x86 boot sector in 16-bit NASM

[ai-chess-engine](https://github.com/ADM1SH/ai-chess-engine) — C++ bitboard move generation, alpha-beta search, UCI protocol

[custom-malloc](https://github.com/ADM1SH/custom-malloc) — Reimplements malloc, free, calloc and realloc over a static memory array
